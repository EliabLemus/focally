# Spec: Pomodoro & Meeting Metrics Analytics

**Milestone**: v0.9.0
**Priority**: High
**Complexity**: Medium

## Context
User wants to capture productivity metrics for pomodoros completed and meeting time spent to generate weekly and monthly usage reports.

## Requirements

### 1. Data Model

Create `FocusSessionRecord` model (JSON-serializable, stored in UserDefaults or SQLite):

```swift
struct FocusSessionRecord: Codable, Identifiable {
    let id: UUID
    let mode: FocusMode  // .focusTime, .meeting, .inbox
    let startTime: Date
    let endTime: Date
    let duration: TimeInterval  // in seconds
    let pomodorosCompleted: Int?  // nil for non-pomodoro modes
}
```

### 2. Storage Service

Create `FocusMetricsService` (ObservableObject, singleton):

```swift
final class FocusMetricsService: ObservableObject {
    static let shared = FocusMetricsService()

    @Published var dailyMetrics: [Date: DailyMetrics] = [:]
    @Published var weeklyMetrics: [Date: WeeklyMetrics] = [:]
    @Published var monthlyMetrics: [Date: MonthlyMetrics] = [:]

    // Aggregated metrics
    struct DailyMetrics: Codable {
        let date: Date
        let pomodorosCompleted: Int
        let meetingTime: TimeInterval  // in seconds
        let totalFocusTime: TimeInterval
    }

    struct WeeklyMetrics: Codable {
        let weekStartDate: Date
        let pomodorosCompleted: Int
        let meetingTime: TimeInterval
        let totalFocusTime: TimeInterval
        let daysWithData: Int
    }

    struct MonthlyMetrics: Codable {
        let monthStartDate: Date
        let pomodorosCompleted: Int
        let meetingTime: TimeInterval
        let totalFocusTime: TimeInterval
        let weeksWithData: Int
    }

    func recordSession(_ session: FocusSessionRecord)
    func getDailyMetrics(for date: Date) -> DailyMetrics?
    func getWeeklyMetrics(for weekStartDate: Date) -> WeeklyMetrics?
    func getMonthlyMetrics(for monthStartDate: Date) -> MonthlyMetrics?
}
```

### 3. Integration with TimerService

Hook into `TimerService` lifecycle events:

- When session completes → call `FocusMetricsService.shared.recordSession()`
- For Focus Time mode → increment pomodoro count based on pomodoro cadence
- For Meeting mode → record meeting duration

## Technical Constraints

- Storage: Use `UserDefaults` with key `focally.metrics.records` for MVP (migrate to SQLite v0.10.0 if > 1000 records)
- Performance: Aggregate daily/weekly/monthly metrics on-demand (cache results for 1 hour)
- Privacy: All data stored locally only (no cloud sync)
- Backwards compatibility: Gracefully handle missing metrics data on first launch

## Notes

- Date boundary handling: Use `Calendar.current.startOfDay` for daily aggregation
- Week calculation: Use `Calendar.current.dateIntervalOfWeek` (ISO week start: Monday)
- Month calculation: Use `Calendar.current.dateInterval(of: .month, for:)`
- Pomodoro count: Calculate from duration / pomodoro cadence (e.g., 25min session with 5min break = 1 pomodoro)
