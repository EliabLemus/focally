## Bug List

### Bug 1: Metrics not recording
**Symptom**: Ran a 1-minute timer but it doesn't appear in metrics.
**Root Cause**: Unknown. Need to verify:
- `FocusTimerService.recordMetricsOnCompletion()` is called
- Session duration >= 5s (threshold from v0.9.1)
- `FocusMetricsService.recordSession()` is called
- UserDefaults saves the record
- Daily/Weekly/Monthly views fetch and display records

**Files to inspect**:
- `Focally/Services/FocusTimerService.swift` (line ~130: `recordMetricsOnCompletion`)
- `Focally/Services/FocusMetricsService.swift` (line ~85: `recordSession`)
- `Focally/Views/Metrics/DailyMetricsView.swift` (fetch and display)

**Debugging**:
- Add `print("[Metrics] Recording session: \(record)")` in `recordSession()`
- Add `print("[Metrics] Total records: \(records.count)")` after recording
- Check UserDefaults key `focally.metrics.records` exists

### Bug 2: Menu bar emoji overlapping pause control
**Symptom**: When focus mode is active, emoji overlaps pause control, can't click pause properly.
**Root Cause**: In `OnItFocusApp.renderMenuBarImage()`, emoji + pause icon + time text are rendered with insufficient spacing.
**Location**: `Focally/OnItFocusApp.swift` (lines 332-387)

**Current logic**:
```swift
let gap: CGFloat = 3  // Too small?
let emojiDim: CGFloat = 14
let iconDim: CGFloat = 10
let totalWidth = padding + emojiDim + gap + iconSize.width + gap + textSize.width + padding
```

**Fix options**:
1. Increase `gap` from 3 → 6
2. Reduce `emojiDim` from 14 → 12
3. Adjust vertical positioning of pause icon
4. Ensure hit testing works on the entire button

---

### Bug 3: Focus mode icons clipped in corner
**Symptom**: When viewing all focus modes, icons appear incomplete/clipped in corner.
**Root Cause**: Unknown. Likely in FocusModeCard or sidebar item layout.
**Files to inspect**:
- `Focally/Views/Timer/FocusModeCard.swift`
- `Focally/Views/Navigation/SidebarItemView.swift`
- `Focally/Views/Timer/ActiveFocusView.swift`

**Possible causes**:
- `frame(width: )` or `frame(height: )` clipping
- Emoji font size too large for container
- Missing `contentShape()` or `fixedSize()`

**Fix**:
- Add `.contentShape(Rectangle())` to prevent clipping
- Ensure emoji has `fixedSize()` or `.frame(minWidth: 20)`
- Check `clipped()` modifiers
