## Bug: Language Picker Not Working

### Symptom
Clicking on another language doesn't change the app language.

### Root Cause Analysis

**Current implementation** (`AppLanguage.swift`):
```swift
@Observable
final class AppLanguage {
    static let shared = AppLanguage()
    var currentLanguage: String

    func setLanguage(_ code: String) {
        guard Self.supportedLanguages.contains(code) else { return }
        currentLanguage = code
        UserDefaults.standard.set(code, forKey: Self.storageKey)
    }

    var locale: Locale {
        Locale(identifier: currentLanguage)
    }
}
```

**Language picker** (`LanguageSettingsView.swift`):
```swift
Button(action: {
    appLanguage.setLanguage(language.code)
}) { ... }
```

**Environment injection** (`OnItFocusApp.swift`):
```swift
// Line 94: Settings window
.windowStyle(.hiddenTitleBar)
.environment(\.locale, appLanguage.locale)

// Line 250: Some other hosting view
.environment(\.locale, appLanguage.locale)
```

**Missing environment**:
- `MainWindow` (opened via `openMainWindow()`) has `.environment(appLanguage)` BUT NO `.environment(\.locale, appLanguage.locale)`

### Why It Doesn't Work

1. **Environment scope**: `.environment(\.locale, ...)` only affects views in that hosting view's subtree
2. **MainWindow locale**: MainWindow doesn't have `.environment(\.locale, ...)`, so it uses system locale
3. **Re-render issue**: Even if locale changes, SwiftUI may not re-render all views without explicit propagation

### Fix Required

**File**: `Focally/OnItFocusApp.swift`

**Find**: `openMainWindow()` function (around line 400-450)

**Current**:
```swift
private func openMainWindow() {
    let hostingView = NSHostingController(rootView: MainWindow()
        .environment(appLanguage))
    hostingView.window?.makeKeyAndOrderFront(nil)
}
```

**Fix to**:
```swift
private func openMainWindow() {
    let hostingView = NSHostingController(rootView: MainWindow()
        .environment(appLanguage)
        .environment(\.locale, appLanguage.locale))  // ADD THIS LINE
    hostingView.window?.makeKeyAndOrderFront(nil)
}
```

**Also verify**: Ensure ALL hosting views have `.environment(\.locale, appLanguage.locale)`:
- Settings window
- MainWindow
- Any popover/sheet hosting views
