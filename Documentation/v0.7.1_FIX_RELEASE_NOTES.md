# Focally v0.7.1 - Quick Fix Release

## What was fixed

1. ✅ **DND Badge** - Now visible in MenuBar dropdown during active sessions
2. ✅ **Version display** - About screen shows correct version (0.7.1)
3. ✅ **Shortcuts drop zone** - Already implemented, now with visual improvements

## How to update

**Force reinstall** (recommended):
```bash
brew reinstall --cask focally
```

**Or wait for brew cache to refresh** (can take up to 1 hour):
```bash
brew update && brew upgrade --cask focally
```

## Verification

After installing, verify:
1. **About screen** → Settings → About → Should show "Version 0.7.1"
2. **DND Badge** → Start a focus session → MenuBar dropdown → Should show "DND Active" badge
3. **Shortcuts zone** → Settings → Integrations → Should see drop zone for .shortcut files

## Troubleshooting

If brew says "already installed":
```bash
brew reinstall --cask focally
```

If shortcuts files don't appear:
1. Open Focally
2. Go to Settings → Integrations
3. You should see a drop zone with "Drag & Drop .shortcut file"
4. Focally automatically generated test shortcuts on first launch in:
   `~/Library/Application Support/Focally/Shortcuts/`
