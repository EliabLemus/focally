## Filosofía

"El repositorio es el sistema de registro" — basado en el enfoque de OpenAI.

Este conocimiento está versionado, indexado y verificado mecánicamente. Cuando una regla cambie, actualiza el archivo correspondiente. Si un archivo se vuelve desactualizado, deprecáalo y crea uno nuevo.

**Regla de oro**: Dale al agente un mapa (este índice), no un manual de 1000 páginas.
