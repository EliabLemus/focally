## Current Issues

### 1. Emoji Picker Not Discovered by Users

**Problem**: Users must know to type `:` to trigger the emoji picker.

**Evidence**:
```swift
// Line 64-77: Only triggers when user types ":"
onChange(of: draftMode.emoji) { _, newValue in
    let trimmed = newValue.trimmingCharacters(in: .whitespacesAndNewlines)
    if trimmed == ":" {
        showEmojiPicker = true
    } else if trimmed.hasPrefix(":") && trimmed.count > 1 {
        showEmojiPicker = true
        searchResults = ...
    } else {
        showEmojiPicker = false
    }
}
```

**User Feedback**: "necesito que todas las cajas de texto que tengan que ver con emojis mejoren"

**Impact**: Low discoverability, users may not know they can use workspace emojis.

---

### 2. UI Hierarchy Confusing

**Problem**: Nested toggles (DND → Pomodoro → Pomodoro Settings) create cognitive load.

**Evidence**:
```swift
// Line 271-289: Three-level nesting
Toggle("edit_mode_enable_dnd", isOn: $draftMode.enableDND)

if draftMode.enableDND {
    Toggle("edit_mode_enable_pomodoro", isOn: $draftMode.enablePomodoro)

    if draftMode.enableDND && draftMode.enablePomodoro {
        DisclosureGroup("edit_mode_pomodoro_settings") {
            // 4 steppers inside
        }
    }
}
```

**User Feedback**: "la ventana de edición de los focus modes, puede mejorar"

**Impact**: Users must navigate multiple levels to adjust basic settings.

## Research: UI Best Practices

### Accordion/DisclosureGroup Guidelines

From [NN/g: Accordions on Desktop](https://www.nngroup.com/articles/accordions-on-desktop/):

> **When to use accordions**:
> - When you need to simplify a long page or reduce scrolling
> - When users need to compare settings (not with accordions)
> - **Avoid for**: Settings that users need to see simultaneously
>
> **Best practices**:
> - Keep headings clear and descriptive
> - Ensure open/close state is visible
> - Avoid excessive nesting (max 2 levels)

**Conclusion**: Current Pomodoro settings violate "avoid excessive nesting" rule.

---

### Emoji Picker UX Patterns

**Industry Standards**:
1. **Trigger**: Button with 😊 icon next to text field
2. **Search**: Instant search within picker (not type-to-search)
3. **Recent**: Grid of recently used emojis
4. **Categories**: Tabs (Recent, People, Nature, Objects, Symbols, Custom)

**Current Implementation**:
- ✅ Trigger: Type `:` (non-standard, hidden)
- ✅ Search: Type-to-search with `:emoji` pattern
- ✅ Recent: Grid of recent emojis
- ❌ Button: No visible trigger button

**Improvement Needed**: Add visible trigger button 😊 next to text fields.

### Phase 2: UI Hierarchy Simplification (Quick Win)

**Goal**: Reduce nesting from 3 levels to 2 levels max.

**Current Structure**:
```
Toggle: Enable DND
  └─ Toggle: Enable Pomodoro
      └─ DisclosureGroup: Pomodoro Settings
          ├─ Stepper: Work
          ├─ Stepper: Short Break
          ├─ Stepper: Long Break
          └─ Stepper: Rounds
```

**Proposed Structure**:

#### Option A: Flat Layout (Recommended)

```
Section: Basic Settings
├─ TextField: Mode Name
├─ Emoji Picker: Mode Emoji
├─ TextField: Status Message + Emoji Button
├─ TextField: Break Label + Emoji Button
└─ Stepper: Duration (5-120 min)

Section: Advanced Settings
├─ Toggle: Enable DND
├─ Toggle: Enable Pomodoro
│
└─ DisclosureGroup: Pomodoro Configuration
    ├─ Stepper: Work (5-120 min)
    ├─ Stepper: Short Break (1-30 min)
    ├─ Stepper: Long Break (5-60 min)
    └─ Stepper: Rounds (1-12)
```

**Implementation**:
```swift
ScrollView {
    VStack(alignment: .leading, spacing: 20) {
        // Section 1: Basic Settings
        Section("edit_mode_section_basic") {
            // Name, Emoji, Status, Break, Duration
        }

        Divider()

        // Section 2: Advanced Settings
        Section("edit_mode_section_advanced") {
            // DND toggle
            Toggle("edit_mode_enable_dnd", isOn: $draftMode.enableDND)

            // Pomodoro toggle
            Toggle("edit_mode_enable_pomodoro", isOn: $draftMode.enablePomodoro)

            // Pomodoro settings (always visible if enabled)
            if draftMode.enablePomodoro {
                DisclosureGroup("edit_mode_pomodoro_settings") {
                    // 4 steppers
                }
                .padding(.top, 8)
            }
        }
    }
}
```

#### Option B: Accordions (Alternative)

```
Accordion: Basic Settings
├─ Mode Name
├─ Mode Emoji
├─ Status Message
├─ Break Label
└─ Duration

Accordion: Advanced Settings
├─ Enable DND
├─ Enable Pomodoro
└─ Pomodoro Configuration (if enabled)
```

**Trade-off**: More clicks to view basic settings.

**Recommendation**: Option A (Flat Layout) - All basic settings visible.
