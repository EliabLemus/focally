### Phase 2: Language Service (30m)

#### Task 2.1: Create AppLanguage.swift
- Create file: `Focally/Models/AppLanguage.swift`
- Implement `@Observable` class with:
  - `static let shared = AppLanguage()`
  - `var currentLanguage: String`
  - `private init()` with auto-detection logic
  - `func setLanguage(_ code: String)`

#### Task 2.2: Auto-Detection Logic
```swift
private init() {
    // 1. Check UserDefaults manual override
    let manual = UserDefaults.standard.string(forKey: "focally.language")
    if let manual = manual, ["en", "es", "pt"].contains(manual) {
        currentLanguage = manual
        return
    }

    // 2. Auto-detect system language
    let systemCode = Locale.current.language.languageCode?.identifier ?? "en"
    currentLanguage = ["es", "pt"].contains(systemCode) ? systemCode : "en"

    // 3. Fallback to English
    if !["en", "es", "pt"].contains(currentLanguage) {
        currentLanguage = "en"
    }
}
```

#### Task 2.3: Inject into OnItFocusApp.swift
- Add to `OnItFocusApp`:
  ```swift
  @State private var appLanguage = AppLanguage.shared
  ```
- Update `contentView` environment:
  ```swift
  .environment(\.locale, Locale(identifier: appLanguage.currentLanguage))
  ```
- Update `hostingView` environment:
  ```swift
  .environment(\.locale, Locale(identifier: appLanguage.currentLanguage))
  ```
