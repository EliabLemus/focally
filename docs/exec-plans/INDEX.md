# Execution Plans

Planes de ejecución para features y tech debt.

---

## Archivos

- **[active/](active/)** — Planes en progreso
- **[completed/](completed/)** — Planes completados
- **[TECH_DEBT_TRACKER.md](TECH_DEBT_TRACKER.md)** — Tracker de deuda técnica

---

## Formato de Plan

```markdown
# PLAN-XXX: [Feature Name]

## Estado
[in_progress | pending | completed]

## Objetivo
[Descripción clara]

## Pasos
1. [Paso 1]
2. [Paso 2]
3. [Paso 3]

## Criterios de Aceptación
- [ ] [Criterio 1]
- [ ] [Criterio 2]

## Notas
[Contexto adicional]
```

---

## Principios

1. **Planes ligeros para cambios pequeños** — Un checklist es suficiente
2. **Planes estructurados para cambios complejos** — Usar el formato arriba
3. **Marcar planes completados** — Mover a `completed/` y actualizar el tracker
